使用目的

整理可供 MKLAB Stock、GitHub Actions、Hermes Agent 或其他程式自動取得的台股官方資料入口，包含股票基本資料、財務報表、營收、股利、估值、交易、籌碼、ETF 與 ESG。

重要：使用前請實測驗證

本文件彙整先前整理的官方資料端點與入口，並非官方保證的永久 API 清單。端點可能改版、移除、調整欄位或限制存取。正式納入 MKLAB 前，請逐一測試 HTTP 狀態、Content-Type、回應本文、欄位、資料期間及上市/上櫃涵蓋範圍。HTTP 200 不代表內容一定是有效資料。若端點無法使用，請以官方 Swagger/網站當期文件重新確認，不要直接假設 URL 正確或資料完整。

8. MOPS 歷史月營收與財報下載

歷史月營收 HTML 路徑範例

✅ 2026-11-14 實測：網址仍可存取，且為當期資料。 上市（sii）與上櫃（otc）皆回 HTTP 200（456 KB／397 KB），出表日期 115/11/14、 資料年月 民國 115 年 9 月，內容為當期月營收（當月營收、上月、去年同月、月增率、年增率、累計）。 編碼為 Big5（CP950）——直接以 UTF-8 解析會整段亂碼，須 decode('cp950')；回傳是 HTML 表格（含產業分組、合計列），需自行解析。

市場示例網址實測
上市（sii）t21sc03_115_9_0.htmlHTTP 200 · 456 KB · 當期
上櫃（otc）t21sc03_115_9_0.htmlHTTP 200 · 397 KB · 當期

路徑參數概念：{市場別} 可為 sii（上市）或 otc（上櫃）；115 為民國年；9 為月份；最後的類別代碼需依官方資料實測確認。這些範例為 HTML，不是 CSV。

建議：只需「上市公司最新月營收」時，改用 OpenAPI 的 t187ap05_L（JSON、免解析 HTML、一檔即全市場）。 MOPS 的 nas HTML 路徑則適合回溯歷史月份或需要含上櫃公司時使用。

XBRL / 財務報告

從 MOPS 官網進入財務報表與 XBRL 相關區域，查找財務報告、XBRL 分類標準及下載功能。可用於取得資產負債表、綜合損益表、現金流量表、權益變動表及會計師查核/核閱資訊。實際下載格式可能是 XBRL、HTML、PDF 或壓縮檔，應以當期下載介面為準。

9. 直接下載與自動化範例

使用 curl 下載 JSON

curl -L "https://openapi.twse.com.tw/v1/opendata/t187ap05_L" -o monthly_revenue.json

使用 JavaScript fetch

const url = "https://openapi.twse.com.tw/v1/opendata/t187ap05_L";
const response = await fetch(url);
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const contentType = response.headers.get("content-type") || "";
if (!contentType.includes("json")) {
  throw new Error(`Unexpected Content-Type: ${contentType}`);
}
const data = await response.json();
if (!Array.isArray(data) || data.length === 0) {
  throw new Error("資料格式錯誤或資料為空");
}
console.log(`取得 ${data.length} 筆資料`);

GitHub Actions / Agent 驗證清單

  • 記錄完整 URL、HTTP Method、查詢參數及抓取時間。
  • 驗證 HTTP 狀態、Content-Type、回應本文與 JSON/CSV 結構。
  • 檢查欄位名稱、資料筆數、日期、代號及重複資料。
  • 區分缺值、數值 0、空字串、無資料及請求失敗。
  • 確認上市與上櫃市場是否都有涵蓋，不能只用上市資料代表全市場。
  • 保留原始回應與標準化資料，方便追查解析錯誤。
  • 確認資料授權、使用條款、頻率限制及 GitHub Actions 執行限制。
  • 失敗時重試並記錄錯誤，不可用空資料覆蓋最後一次有效資料。

10. MKLAB 建議導入順序

  1. 基本主檔：上市/上櫃公司代號、名稱、產業分類、新上市與終止上市資訊。
  2. 歷史基本面：月營收、季度財報、EPS、現金流量與資產負債表。
  3. 股利歷史：現金股利、股票股利、除權息日、決議狀態與實際發放資訊。
  4. 估值交易：PE、PB、殖利率、日收盤價、成交量與歷史價格。
  5. 籌碼資料：融資融券、外資持股、董監事及內部人持股。
  6. ETF：ETF 主檔、成分股、配息、淨值及定期定額排行。
  7. ESG：溫室氣體、能源、水資源、廢棄物及公司治理資料。

  • t187ap06_L_fh（金控損益表）只回 1 筆全空資料，故金融保險類無官方 EPS； 目前以「官方 PE 反推 TTM EPS」處理（eps_src = TWSE_PE_IMPLIED）。

  • t187ap06_L_basi（銀行損益表）有資料但只 9 家（2801、2812…），不含大型金控。
